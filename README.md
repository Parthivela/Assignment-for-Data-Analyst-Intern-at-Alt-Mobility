# Assignment for Data Analyst Intern at Alt Mobility

This repository contains SQL queries, visualizations, and summary findings for the Data Analyst Intern assignment by **Alt Mobility**.

The project includes:
- Structured analysis of **orders**, **payments**, and **customer behavior**
- **Cohort-based customer retention analysis**
- Key insights to support decision-making in fleet operations and customer engagement

The goal of this analysis is to uncover trends in order fulfillment, customer purchase behavior, payment success rates, and monthly retention patterns using SQL and data visualization tools.
